# DATA-VALIDATION-SYSTEM


About the Project
This project is a Java-based Data Validation System developed using NetBeans. The system is designed to collect user information and check that the information entered is valid before it is accepted.

Features
1. Validates user information
2. Checks required fields
3.Validates age input
4. Allows gender selection
5. Displays validation messages
6. Provides Save, Clear, Help and Exit buttons
7. Uses a simple and user-friendly interface

Technologies Used
1. Java
2. Java Swing
3. NetBeans IDE

Purpose
The purpose of this project is to demonstrate the use of Java programming, graphical user interfaces, input validation and event handling.
